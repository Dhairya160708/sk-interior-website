# S K Interior Landing Page

A responsive landing page demo for an interior design studio, built with plain HTML, CSS and JavaScript.

**Live demo:** https://dhairya160708.github.io/sk-interior-website/

## Tech stack

- HTML5
- CSS3
- Vanilla JavaScript (no frameworks or build step)

## Run locally

Clone the repo and open `index.html` in your browser. No installation needed.

## Project structure

- `index.html` - page markup
- `style.css` - styles
- `main.js` - interactions
- `assets/` - images and other static files

> This is a demo project built for portfolio purposes.
